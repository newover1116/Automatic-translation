# 화면 번역기 (Screen Translator)

안드로이드 화면 위에 실시간으로 번역을 띄워 주는 앱이에요. 글자 인식과 번역 모두 기기 안에서 동작해요 (Google ML Kit).

## 설치
1. 이 저장소의 **Releases** → 가장 위 빌드 → `ScreenTranslator-숫자.apk` 다운로드
2. 폰에서 "출처를 알 수 없는 앱 설치"를 허용하고 설치
3. 새 버전도 같은 방법으로 받아서 덮어 설치하면 돼요

## 사용법
- **번역 시작** → '다른 앱 위에 표시'와 화면 캡처 허용
- 동그란 **번역** 버튼 탭 → 화면 글자 위에 한국어 번역 표시
- 다시 탭 → 화면이 그대로면 지우고, 바뀌었으면 새로 번역
- **길게 누르기** → 메뉴 (자동 번역 / 번역 영역 지정 / 종료)
- 버튼은 끌어서 옮길 수 있어요

## 지원 언어
영어·일본어·중국어 → 한국어

## 빌드
`main` 브랜치에 올리면 GitHub Actions가 자동으로 APK를 만들어 Releases에 올려요.
