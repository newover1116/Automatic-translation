# 게임 번역기

게임 파일을 넣으면 한국어로 번역해 주는 안드로이드 앱입니다.

## 지원 형식

| 형식 | 번역 범위 |
|---|---|
| RPG 쯔꾸르 MV/MZ (APK, ZIP) | 대사, 선택지, 아이템, 스킬, 시스템 문구 |
| 렌파이 `.rpy` (ZIP, 단일 파일) | 대사, 선택지, 캐릭터 이름, 화면 문구. 한글 글꼴 자동 추가 |
| HTML5 게임 (`.js`), Lua 스크립트 | 코드 속 문장 (비교값, 키, 경로는 제외) |
| 티라노빌더 `.ks` | 대사 줄 |
| 일반 안드로이드 앱 방식 게임 | `resources.arsc` 문자열 |
| JSON, CSV, TSV, XML, TXT, YAML, INI, `.properties`, `.lang` | 문장으로 판단되는 값 |
| APK가 든 ZIP | 안의 APK를 자동으로 꺼내 번역 |

## 번역되지 않는 것

유니티, 언리얼, 고도, 게임메이커, 디폴드, Solar2D처럼 게임 본문이 컴파일된 파일 안에 있는 경우와 렌파이 `.rpyc`/`.rpa`, 쯔꾸르 VX Ace 이하, KiriKiri, 울프 RPG, 이미지 속 글자는 번역되지 않습니다. 분석 화면에서 미리 알려 줍니다.

## 번역 엔진

- 무료 기기 번역: ML Kit, API 키 필요 없음
- Gemini: API 키 필요, 문맥을 이해해 품질이 더 좋음

번역한 게임은 개인적으로만 사용해 주세요.
